# 译文写法

翻译、修订时的译文写法。这是**插件默认**的风格文件：项目里的 `.wikipali/styles/translation.md`
或个人的 `~/.wikipali/styles/translation.md` 存在时，以它为准；它没写到的事项仍按本文件（`wikipali-style` 负责查找）。
本文件对 wikipali-workspace 的所有 skill 一律有效；坐标、引用格式、
文献层次、译文来源判定这些**数据层**的约定在底层插件里，用 `wikipali guide conventions` 读。
审稿定级见同目录的 `translation-evaluate.md`。

## 译文风格：默认现代汉语

用户没有指定风格时，一律用**现代汉语**——通顺的书面语。

- **不要古汉语**
- **不要半文半白**
- **不要模仿古代译经的腔调**——「尔时」「复次」「者……也」「谓」「如是」这类仿古
  句式一概不用

术语该用哪个词就用哪个词，但**句子结构与虚词一律现代汉语**。这些译文是给今天读
巴利的人看的；仿古会让读者误以为手里是一份古代译本，而它不是。

常见的文言写法与现代改法：

| 不用（文言 / 半文半白） | 改用（现代书面汉语） |
|---|---|
| 注曰、曰、云 | 说、说道、解释说 |
| 年方七岁 | 七岁时 |
| 身着盛装 | 穿着华丽的衣服 |
| 端坐父膝 | 端正地坐在父亲膝上 |
| 在家用膳毕、用膳 | 在家吃完饭后、吃 |
| 于…之际、当…之时 | 在…的时候、当…时 |
| 即证阿罗汉果 | 就证得了阿罗汉果 |
| 答以「是」 | 回答说「是」 |
| 便（=于是）、遂 | 就、于是 |
| 此类人、此人 | 这样的人、这个人 |
| 此中、故为、彼等、是故、若…则 | 这里、因此是、他们、所以、如果…就 |
| 谓、乃、之、其、以、所（作文言虚词时） | 用现代对应词或直接省略 |

**总原则**：能用双音节现代词就不用单音节文言词（之 / 其 / 乃 / 便 / 即 / 於 / 遂）；
不用文言句式（…者，…也／于…之际／经…后／答以…）。**判定标准**：读给没有古文基础的
现代读者听，有任何一句让他觉得像古文，就不合格。宁可句子长一点、白一点。

## 术语标记 `[[词根]]`（默认不用）

**默认正常翻译**，术语译成目标语言。只有用户**明确要求**术语标记时才用；用户说不要
标记时同样正常翻译。不要自作主张加上。

要求时的样子——巴利术语保留巴利原词并加双方括号：

```
那时，[[āyasmā]] [[seyyasaka]] 不乐于修习 [[brahmacariya]]。
当你生起 [[anabhirati]]、[[rāga]] 扰乱你的 [[citta]] 时……
```

**范围**：专名（人、地、经书）与教理术语。**普通词照常翻译**，哪怕它出现在佛典里——
`kiso lūkho`（消瘦、憔悴）、`yāvadatthaṃ bhuñja`（随意地吃）是状貌与动作，
`asuci`（不净）是普通名词而非教理术语。拿不准就问用户，别自己扩大范围。

两条硬要求：

- **用词典形**，不用原文里的变格形：`seyyasako` / `seyyasakaṃ` / 呼格 `seyyasaka`
  一律写成 `[[seyyasaka]]`。
- **写之前用 `wikipali forms <词>` 验一遍**——展不出词形的不是有效词根，链接会落空。

## 注释写在译文里（默认不加）

用户要求加注释时，**注释紧跟被注释词，用反引号包裹**，不另起一行、不放段末：

```
不乐于`**义注**：心散乱、被欲贪的热恼所烧，但**并非希求还俗**`修习 [[brahmacariya]]。
```

- **位置**：紧接被注释词之后，中间不留空格
- **不能有换行**——一条注释就是一段连续文本
- 可以用 `**黑体**` 强调
- **注释来源必须标出**（`**义注**：`、`**复注**：`）。义注的说法不是根本的说法，
  混为一谈是学术错误
- 注释内容里的巴利词**不要**再加 `[[ ]]`
- 该句没有可注的就不加，不要为了均匀硬凑

注释内容从 `wikipali related <坐标>` 找到的义注、复注里取，**不要自己发挥**。

**建议**（不是硬约束）：

- **注释要体现义注的主要意思，不是只摘一句。** 义注往往对一段有大量解说——列举
  分类、给出定义、辨析异说、补出根本里没说的背景。只挑最短的一条会让读者以为
  义注就这么点内容。**先把该段的义注读完，再决定注什么。**
- **用通俗易懂的话把义注的意思说出来**，不必逐字直译义注的文言句式。注释是给
  读者解惑的，不是义注的第二份译文。
- 逐段核对一遍：根本的每一段义注都读过了吗？该段真的没有可注的，才不注。

## 被解释词必须与所注文本用词一致（硬约束）

义注（aṭṭhakathā）里的**黑体**是从根本（mūla）原样引出的**被解释词**；复注（ṭīkā）
里的被解释词同样引自义注。同一个 channel 内：

- 义注里被解释词的译法，必须与**根本**同一处的译法逐字相同
- 复注里被解释词的译法，必须与**义注**对应处的译法逐字相同

一旦不一致，读者就看不出这条注在注哪个词——注释与被注文本的对应关系断裂，
而这是随文注唯一的线索。

**翻译、校对、审稿、评估一律适用。** 这条可以机械核查：把义注的黑体词抽出来，
到根本同一坐标比对字符串；不等就是错，不是风格问题（`translation-evaluate.md` 里归
`error`「用词不符」）。
